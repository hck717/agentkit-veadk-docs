### 安全對 agentic adoption 的關鍵性  
Agentic adoption（代理型 adoption）需要管理多個 coding agents（如 Anthropic、OpenAI 等），並確保其在客戶 GitHub 倉庫中的有序運作。安全是這一過程的關鍵前提，因為代理型工具涉及處理敏感的代碼庫、外部 API 集成以及多來源上下文（如電子郵件、會議記錄、文檔等）。缺乏安全措施可能導致數據洩露、未授權訪問或操作風險。例如，Microsoft 在 Defender、Entra、Intune 和 Purview 中添加了十多個新的安全 Copilot 代理，並將 Security Copilot 推廣到所有 E5 客戶，以簡化安全團隊的上門流程。這些安全工具可監控和管理代理活動，識別風險信號，並提供可觀察性，而這些都是代理型 adoption 的必要條件【KB:Microsoft_Corp_Earnings_Call_2026128_RT000000003094331726.pdf.txt】。
