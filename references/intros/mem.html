🎯 一句心法：Agent 嘅「記憶」係一條流水線——記憶三層（短期會話 STM / 長期記憶 LTM / 知識庫 KB）幾時寫、點帶返，最後全部湧入每輪 context。呢頁教點控制個 context（top_k / compaction / 切 session / cache 協同）：短 = 快 + 平 + 準。
