📘 呢頁詳細解說（先睇呢度，再落下面文件）

呢個 Tab 有兩份 API 文件：VeADK 框架（靈活、完整、Agent 為中心）同 AgentKit SDK（簡潔、App 為中心、A2A 原生）。寫 Agent 前先搞清楚兩者定位：

VeADK（框架） AgentKit SDK（輕量）
心智模型 Agent 組裝（model/tools/memory/kb/instruction） Agentkit*App 一把過（AgentkitSimpleApp/MCPApp/A2aApp）
靈活度 高：A2UI、Feishu、知識庫、短期記憶逐樣配 低但快速：少 boilerplate
適合 複雜多模態 / 需要完整 control 快速 demo、單一 LLM agent、MCP/A2A 包裝
部署 都要經 ak deploy / runtime 同左

💡 當刻路：新起項目優先試 AgentKit SDK 睇啱唔啱；需要知識庫 / 團隊本地工具 / 自訂 runner 先上行 VeADK。

VeADK 核心概念（一張圖）

Agent(model, tools=[], knowledgebase=kb, longterm_memory=ltm, instruction=...)
   └── Runner.run(session, task)
          ├── 自動載入 knowledge / memory / 工具
          └── 產生 session events（含 usage_metadata → 睇 cache 命中）

建立 Agent + Runner（最短範例）

from veadk import Agent, Runner, KnowledgeBase

agent = Agent(
    model="doubao-seed-2-0-mini",
    knowledgebase=KnowledgeBase(backend="viking", index="docs"),
    instruction="用粵語回答；答案引用返知識庫出處。",
)
runner = Runner(agent)
response = runner.run(session, task="公司請假流程係點？")

記憶 & 知識庫（三個層，唔好混）

層 VeADK 元件 幾時用
短期記憶（session） Runner / session 內建 每輪對話 context
長期記憶（LTM） LongTermMemory(backend="viking") 跨 session 記住用戶偏好
知識庫（KB） KnowledgeBase(backend="viking") 靜態文檔 RAG

後端矩陣同揀法詳見「記憶 / 知識庫」Tab；Backend 揀錯 = 價錢同速度兩頭唔到岸。

工具（Tools）

  • VeADK 內建：load_knowledgebase（RAG）、build_crud_ops（自動 CRUD）、code_executor（Code Runner）、browser_*、image_*、Feishu 工具。
  • 用 第三方工具（MCP）時，agent_mcp_toolset 令 Agent 直接識 call 外部 MCP server——動態注入 tool 定義（SDK 都有「每輪注入工具定義」選項提升多輪穩定性）。

A2UI + Feishu（前端 / 通知，一樣源自 ADK 生態）

  • A2UI：app = A2UIApp(agent=...)，裝緊 render 走唔様 A2UI 介面（input box + token/turn 統計）。
  • Feishu：用 LarkApp / Feishu 工具組將 agent 接入飛書 bot，多字對話流狀態。

⚠️ output_schema 會關 context cache（見 VectorCache Tab）：要結構化抽取 + 慳錢要識取捨。

AgentKit SDK 核心概念（一把過）

from agentkit_sdk import AgentkitSimpleApp, A2aApp, AgentkitMCPApp

app = AgentkitSimpleApp(model="doubao-seed-2-0-mini", system_prompt="你係客服")
# 或 MCP：
app = AgentkitMCPApp(name="my-mcp-app", mcp_server_config={...})
  • A2aApp：將 agent 以 A2A registry 發佈，其他 agent / 沙箱可直接 A2A 調用（見「invoice-pipeline」A2A drive-chain 實作）。
  • 平台 client：AgentKit 會自動帶 client（平台 credential），connect 到你嘅 runtime。
  • Tool：@tool 裝飾器定義自訂工具，自動做成 JSON schema（SDK/CLI 都支援「結構化工具調用」）。

寫完好唔好？睇 3 個位

  1. call 得郁：agentkit invoke my-agent -m "test"（見 CLI Tab）。
  2. 唔好爆 context：睇 response usage_metadata 命中率（見性能 / 記憶 Tab）。
  3. 有 eval 過：ak eval run 幫 agent 開個 qa-set 驗證先當「寫完」。

記住

  • VeADK ≠ AgentKit SDK；職責唔同、好唔好咪。複雜 agent 用 VeADK，包裝/快速用 SDK。
  • mock 試線 vs 真 model：本地開發可以 mock=True，確認 orchestration 啱先切真 model（睇 invoice-pipeline 嘅 --no-mock 模式）。
